# Fourier and sampling exercises

[learn.ipynb](learn.ipynb) explores classical FFT, DFT, inverse DFT, signal sampling, filtering, and aliasing. This notebook does not implement quantum Fourier transforms.

Install dependencies from the repository root.

```powershell
.\.venv\Scripts\python.exe -m pip install -r learning/fourier-and-sampling/requirements.txt
```

Open the notebook in a Jupyter-compatible editor and select the repository's `.venv` kernel.
